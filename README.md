An entry for [Office Artifacts: The One-Line Placard Contest](https://make.fun/c/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on [make.fun](https://make.fun).

`main.ts` writes a single museum placard line — a stapler recast as a Bronze Age ritual instrument of the Binding Clerks — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is 178 characters, one line, deterministic on every run.

Run it with Node 22+:

```sh
node main.ts
```
